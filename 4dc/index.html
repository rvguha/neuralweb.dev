Data Commons on NeuralWeb

Two ways to use Google Data Commons statistics: find which variable documents describe a quantity, or ask a question and get the values.

ARD search over Data Commons ARD + OKF · 6,460 documents, 5,213 variables Search the catalog: one document per source and variable, each saying what it measures, where it comes from, what places and years it covers and how to fetch it. “unemployment rate by state” Neural DB over Data Commons Neural DB · answers with values Ask a question in plain English. The Data Commons plugin picks the variable and source, resolves the place and returns the value with its period. “What is the unemployment rate in Texas?”
