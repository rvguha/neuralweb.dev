NeuralWeb

Research services for answering questions from public data.

NeuralKG2

Ask a data question in plain English. Answers come live from public sources (Census, SEC, IRS Form 990, CDC, World Bank, UN SDG and more), each value with its source, entity and period.

ARD Agent Finder

Finds which public data tables can answer a question: a search service over about 13,000 documents describing public data sources.

QD RSS

Query Defined RSS: a natural-language query is a feed over a corpus of podcast and news feeds.
